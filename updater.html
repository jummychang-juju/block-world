❓ 第一次使用：如何取得 Token（只要做一次）
  1. Safari 開 github.com/settings/personal-access-tokens/new
  2. Token name 隨便取（例如 blockworld）
  3. Expiration 選 Custom 挑一年後的日期（或 90 days）
  4. Repository access 選 Only select repositories → 勾 block-world
  5. Permissions → Repository permissions → 找到 Contents → 選 Read and write
  6. 按最下面 Generate token → 把整串文字複製，貼到上面的欄位
